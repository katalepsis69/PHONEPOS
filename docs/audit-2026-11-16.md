### Category 1: Correctness and bugs

#67 [LOW] [CONFIRMED] src/license.js:258-262 with src/settings.js:5-11 and src/server.js:912-918
What: getTrialState mints a random per-install secret and stores it as shop_settings key
trial_seal_secret (the 11-15 #25 fix). PRIVATE_SETTINGS was not extended with that key, so
getShopSettings returns it and GET /api/settings sends it to any session, staff included.
Trigger: any logged-in seat opens Settings; the payload includes trial_seal_secret.
Impact: a secret that exists to make seal recomputation require DB read access is now
readable through the API. A user who edits the database still needs write access, so the
practical loss is small, but the project's own PRIVATE_SETTINGS invariant is broken for a
key the #25 fix sketch said to store "like counter_session_secret, which IS in
PRIVATE_SETTINGS".
Fix sketch: add 'trial_seal_secret' to PRIVATE_SETTINGS; pin it with a serverTest that
seeds the key and asserts GET /api/settings omits it.

#68 [LOW] [CONFIRMED] public/js/views/repairs.js:97-118 with public/js/receipts.js:716-718
What: autoPrintSlip now returns 'locked' while another print send is open (the #15 fix).
The sale and claim-stub callers branch on 'locked', but the pickup-slip button awaits
autoPrintSlip and discards the result: the held-lock case prints nothing and says nothing.
Trigger: press Pickup slip while a sale or settlement send is still in flight.
Impact: the pickup notice is silently not printed; a second press works. Same defect class
as #15, one caller missed.
Fix sketch: await the result and toast on 'locked'; add a small i18n key for pickup.
